🔐 Prototype Security Notice

For this no-database prototype, account credentials are stored in localStorage so the other prototype pages can read them. Do not use real passwords or real patient/staff data in this version. In production, passwords should be hashed server-side and invitations should use secure one-time links instead of emailing passwords.
